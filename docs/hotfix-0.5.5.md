# 0.5.5 插件执行与缓存修复

本次保留 0.5.4 的设计：插件优先执行，失败回退同一插件提取的规则，来源不设逐源测试通过门槛。

- `if-eqz / if-nez` 区分非空引用和 null；寄存器引用比较按对象身份，容器查找保留字符串内容比较。
- `const-wide` 读取全部 64 位；`move/16`、`move-wide/16`、`move-object/16` 读取完整源 / 目标寄存器；修复 `/lit8`、反向减法、sparse-switch、第 5 个调用 / 数组参数及 array-length 的长度。
- 静态字段先加载 DEX 初值，再执行类初始化；修复奇数指令填充和异常处理表的字节偏移。
- OkHttp 的 `newCall` 正确传递 RequestBox。网络错误保留原始错误；网络等待每 50ms 检查取消 / 执行超时，结束后取消未完成请求。
- 字节码执行上限为 2000 万步 / 45 秒；父任务取消会通过同步控制对象传递到解释器和网络垫片。
- 规则提取和解释器共享插件缓存；以完整 URL + MD5 为身份，下载校验 MD5，合并同包并发下载。无版本变化时 6 小时更新；显式导入配置会清除该包缓存、规则内存和采集器失败冷却。
- 并发解析不同插件不再共用错误的 in-flight 任务；更新时旧任务不能回填新缓存。
- 设置与关于页说明同步实际实现，不再显示已移除的豆瓣推荐功能。

新增回归实际执行 DEX 方法，覆盖引用判断、宽常量、高位寄存器、立即数、稀疏分支、5 参数、异常捕获、取消 / 超时、HTTP 请求及插件缓存隔离 / 刷新。已有真实插件包测试继续保留。域名和选择器仍来自配置及插件，本次未加入站点专用适配器。

验证进行中，完成后记录于 `validation.md`。实体 iPhone、所有线上来源和直播频道尚未逐一验证。
