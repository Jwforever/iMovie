# 0.4.1 快速修复

本版按 2026-11-11 新反馈修改：

- 首页轮播使用当前来源首页排序前 6 条。直接通过该影片 ID 进入详情，无二次搜索、无豆瓣请求，去掉异步同名查找的“未找到”竞态。网站要求验证时，详情页提供验证入口。
- 缩略图后台 ImageIO 下采样到最多 600 像素，缓存解码后的图片；减少图片缓存目录清理频率，降低滑动时解码和 I/O 工作。真机帧率尚未测量。
- Kimentanm 直播列表优先直连原始 GitHub 地址；直播列表 URLSession 与 AVPlayer 认证委托接受服务器证书，普通配置与点播请求维持原处理。没有逐一实测全部频道的证书和播放。
- 新播放记录与收藏保存影片海报，列表和最近播放采用正方形缩略图；M3U 读取 tvg-logo。旧记录中没有海报的条目保留正方形占位，重新播放后更新。
- 从其他标签切入搜索时创建新搜索会话，清空关键词、结果、来源筛选和旧请求。
- 全局和源内搜索扩展词组 / 部分片名，最多 3 个查询，合并去重后按相关度排序。实际召回仍受来源接口和网站验证限制。

保留 0.4.0 的全部 Android CSP 通用尝试、数据规则、HTTP 取址、详情内播放器和横竖屏会话修复。当前版本 0.4.1 / build 5，最低 iOS 16。
