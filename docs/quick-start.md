# iMovie 0.3.0 快速上手

适用设备：iOS / iPadOS 16 及以上。日常使用只需要 iPhone / iPad 联网。

## 安装

把 `iMovie-0.3.0-unsigned.ipa` 导入自己的 iOS 签名工具，使用自己的证书和描述文件签名、安装。未签名 IPA 不能直接点击安装；如果工具需要唯一 Bundle ID，可从默认的 `local.imovie.player` 改成自己的标识。

安装后的信任、开发者模式和续签步骤，按所用签名工具的说明操作。无需 Android 设备或额外解析服务器。

## 先用奥特浏览播放

1. 打开 iMovie →「设置」。接口已填为 `http://www.饭太硬.cc/tv`。
2. 点击「导入 / 更新配置」。本次配置应出现 48 个点播来源、6 个直播列表；数字可能随接口更新变化。
3. 回到「首页」，点左上角来源名称选择「🏝奥特┃多线」。应用会记住这次选择。
4. 从推荐海报或上方分类中选择影片，打开详情后选择集数；本轮以「折月亮」第 1 集完成验证，节目会随网站更新。
5. 能识别公开 HLS 时直接进入系统播放器；若打开播放网页，顶部出现「已找到媒体地址」后，点击「系统播放」。系统播放器可以调节进度、倍速和全屏。

这条流程已在 iPhone 16 / iOS 18.5 模拟器验证。奥特关键词搜索可能要求手动验证码，可以先从首页浏览。第三方网站的地址、节目和可用性会变化；实体 iPhone 仍需要你签名安装后确认。

动漫巴士可选「🚌巴士┃动漫」，搜索「神厨狂后」后选集并从网页切换系统播放；这条流程旧版通过，本轮云端搜索出现「无法连接服务器」。遇到连接错误可稍后重试或切换来源，不能把连接失败当作没有影片。

## 其他使用方式

- 首页上方是当前来源的分类，默认「推荐」显示来源首页内容；播放后首页会出现「最近播放」，可直接继续观看。
- 左上角来源选择器支持查找来源。未移植来源仍可查看状态，但没有可执行的采集适配。
- 「搜索」：并行查询已适配且允许搜索的站点。多个 B站分类条目合并查询，结果显示真实站点数、失败情况；单个来源可重试。
- 「🏝奥特┃多线」已增加本机适配，当前站点为 Auete 的 `www.aeete.com`。搜索可能要求验证码，出现提示时点击「在网页中验证后重试」，完成网站验证后点「验证完成，重试」。该步骤由用户在网页内操作。
- 「直播」：打开配置中的 HTTP 直播列表，或填入自己的 M3U / TXT 地址。依赖 Android localhost 代理的列表不可用。
- 「首页 → 右上角链接图标」：直接播放 MP4 / HLS；网页地址请开启「使用内置网页播放器」。
- 播放页点击书签图标收藏；「我的」中可重播或查看记录。已适配来源重播会重新请求播放地址。
- 如果网页里有内容、系统播放器却失败，可关闭系统播放页继续使用网页播放器。

## 当前范围

奥特首页到系统播放已完成 iOS 模拟器验证，搜索需要时由用户完成网站验证码。动漫巴士保留旧版完整播放证据，本轮云端连接异常，最终回归状态见 `validation.md`。B站公开单文件视频、兔小贝已有独立适配和网络验证；立播当前域名在云端遇到 HTTP 403。其余标为「待移植」「脚本待适配」的条目，当前版本还不能解析。

应用不包含完整 Android 插件或 drpy 运行环境。更多来源的移植、登录 / 会员 / 网盘、DRM、下载、弹幕和 DLNA 尚未完成。
