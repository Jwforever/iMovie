# iMovie 0.2.0 快速上手

适用设备：iOS / iPadOS 16 及以上。日常使用只需要 iPhone / iPad 联网。

## 安装

把 `iMovie-0.2.0-unsigned.ipa` 导入自己的 iOS 签名工具，使用自己的证书和描述文件签名、安装。未签名 IPA 不能直接点击安装；如果工具需要唯一 Bundle ID，可从默认的 `local.imovie.player` 改成自己的标识。

安装后的信任、开发者模式和续签步骤，按所用签名工具的说明操作。无需 Android 设备或额外解析服务器。

## 先验证动漫巴士

1. 打开 iMovie →「设置」。接口已填为 `http://www.饭太硬.cc/tv`。
2. 点击「导入 / 更新配置」。本次配置应出现 48 个点播来源、6 个直播列表；数字可能随接口更新变化。
3. 进入「片库」，选择「🚌巴士┃动漫」。已适配条目排在前面。
4. 搜索「神厨狂后」，打开结果，选择集数。
5. 播放网页顶部出现「已找到媒体地址」后，点击「系统播放」。系统播放器可以调节进度、倍速和全屏。

这条流程已在 iPhone 16 / iOS 18.5 模拟器验证。第三方网站的地址、节目和可用性会变化；实体 iPhone 仍需要你签名安装后确认。

## 其他使用方式

- 「搜索」：同时查询已适配且允许搜索的来源；某个来源报错时其他结果仍可显示。
- 「直播」：打开配置中的 HTTP 直播列表，或填入自己的 M3U / TXT 地址。依赖 Android localhost 代理的列表不可用。
- 「片库 → 打开播放地址」：直接播放 MP4 / HLS；网页地址请开启「使用内置网页播放器」。
- 播放页点击书签图标收藏；「我的」中可重播或查看记录。已适配来源重播会重新请求播放地址。
- 如果网页里有内容、系统播放器却失败，可关闭系统播放页继续使用网页播放器。

## 当前范围

动漫巴士通过完整的 iOS 模拟器播放测试。B站公开单文件视频、兔小贝已有独立适配和网络验证；立播适配仍属实验。其余标为「待移植」「脚本待适配」的条目，当前版本还不能解析。

应用不包含完整 Android 插件或 drpy 运行环境。更多来源的移植、登录 / 会员 / 网盘、DRM、下载、弹幕和 DLNA 尚未完成。
