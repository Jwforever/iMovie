# iMovie 0.4.1 快速上手

本次安装文件为 `iMovie-0.4.1-unsigned.ipa`。首页轮播现用本站前 6 条热播内容，点击直接进详情，不再拉豆瓣或二次搜索；遇到验证可点详情页「打开网站验证」。搜索每次从其他标签进入会清空，支持关键词模糊扩展；收藏和播放记录采用正方形海报，新记录自动保存资源图。其余最新变更见 `hotfix-0.4.1.md`，下方 0.4.0 的豆瓣相关说明已被本段替代。

适用设备：iOS / iPadOS 16 及以上。日常使用只需要 iPhone / iPad 联网。

## 安装

把 `iMovie-0.4.0-unsigned.ipa` 导入自己的 iOS 签名工具，使用自己的证书和描述文件签名、安装。未签名 IPA 不能直接点击安装；如果工具需要唯一 Bundle ID，可从默认的 `local.imovie.player` 改成自己的标识。

安装后的信任、开发者模式和续签步骤，按所用签名工具的说明操作。无需 Android 设备或额外解析服务器。

## 先用奥特浏览播放

1. 打开 iMovie →「设置」。接口已填为 `http://www.饭太硬.cc/tv`。
2. 点击「导入 / 更新配置」。本次配置应出现 48 个点播来源、6 个直播列表；数字可能随接口更新变化。
3. 回到「首页」，点左上角来源名称选择「🏝奥特┃多线」。应用会记住这次选择。
4. 从推荐海报或上方分类中选择影片，打开详情后选择集数；本轮以「折月亮」第 1 集完成验证，节目会随网站更新。
5. 进入详情页先显示封面与简介，播放器不取址、不加载。选择集数后上方自动替换为系统播放器并播放，不展示原播放网页；支持进度调节和系统全屏，倍速入口已移除。

这条流程已在 iPhone 16 / iOS 18.5 模拟器验证。奥特关键词搜索可能要求手动验证码，可以先从首页浏览。第三方网站的地址、节目和可用性会变化；实体 iPhone 仍需要你签名安装后确认。

动漫巴士可选「🚌巴士┃动漫」，搜索「神厨狂后」后选集，应用会请求其公开播放器接口取址后在详情页内播放。这条无需展示网页的流程已通过模拟器。遇到连接错误可稍后重试或切换来源，不能把连接失败当作没有影片。

## 其他使用方式

- 首页上方是当前来源的分类，默认「推荐」显示来源首页内容；播放后首页会出现「最近播放」，可直接继续观看。
- 左上角来源选择器支持查找来源。全部 Android CSP 已开放，可直接点击「通用尝试」中的来源；无需等逐源测试通过。未知来源进入统一的 HTML / JSON 流程，失败会显示原因。
- 「设置 → 来源地址 / 通用规则」可补充官网、JSON 接口、搜索模板及 CSS 规则；规则保存在本机，重启和更新原配置后继续生效。缺地址的来源失败页也有规则入口。示例见 `generic-source-rules.md`。
- 「搜索」：左侧首项为「全部源」，下面是站点列表；点击即可过滤右侧结果。右侧按片名匹配度从高到低排序，完整片名优先。多个 B站分类条目合并查询，单个来源可重试。
- 「🏝奥特┃多线」已增加本机适配，当前站点为 Auete 的 `www.aeete.com`。搜索可能要求验证码，出现提示时点击「在网页中验证后重试」，完成网站验证后点「验证完成，重试」。该步骤由用户在网页内操作。
- 「直播」：打开配置中的 HTTP 直播列表，或填入自己的 M3U / TXT 地址。依赖 Android localhost 代理的列表不可用。
- 「首页 → 右上角链接图标」：直接播放 MP4 / HLS；网页地址请开启「从网页地址提取视频链接」，识别成功后自动系统播放，无法取址会显示原因。
- 播放页点击书签图标收藏；「我的」中可重播或查看记录。已适配来源重播会重新请求播放地址。
- 「今日推荐」可左右滑动，按豆瓣公开榜单真实评分推荐 6 部影片，点选后在当前来源查找同名作品；评分读取失败时显示来源推荐，不虚构分数。
- 「设置 → 缓存」查看图片和片库 / 推荐缓存用量，可一键清理。图片跨页面和重启复用；播放地址每次按需获取。
- 「设置 → 关于 iMovie」查看软件介绍、版本、GitHub 地址和开发者署名 by Chris Wei。

## 当前范围

奥特首页到系统播放、动漫巴士搜索到系统播放均通过不展示网页的 iOS 模拟器验证；奥特搜索需要时由用户完成网站验证码。9 项界面流程最终结果见 `validation.md`。急救教学新增公开 MP4 适配；B站、兔小贝和急救尚未完成各自 iOS 播放验证，立播受 HTTP 403 限制。当前 12 个配置条目由 6 套专用适配识别，其余 34 个 Android 条目全部走通用尝试，另有 2 个 drpy 条目缺完整脚本宿主。详见 `source-port-status.json`。

后续饭太硬新增来源，点击「导入 / 更新配置」即可自动纳入未知 CSP 通用尝试；沿用已支持结构时只需地址或规则更新。只有 Android 类名无法自动得到真实域名，全新的签名、网盘登录或专有协议仍需扩展引擎，不能保证所有源都能出播放链接。

应用不包含 Android 插件或完整 drpy 运行环境。来源已经开放尝试，登录 / 会员 / 网盘、DRM、下载、弹幕和 DLNA 的完整协议尚未实现。
